### 研究方向

**集群协同导航**  
面向卫星拒止与跨域场景，研究基于节点间相对量测的协同定位、误差抑制与自主重构。

**TDOA / FDOA / AOA 定位**  
完成协同导航模型构建与解算算法实现，覆盖 MATLAB 仿真到 C/C++ 算法验证的完整链路。

**分簇与构型优化**  
针对大规模集群的可扩展性，提出自适应分簇与协同导航构型优化方法，提升整体导航性能。

**系统总体与验证**  
雷达系统指标分解、外场联调联试组织、数据处理与指标验证平台开发。
